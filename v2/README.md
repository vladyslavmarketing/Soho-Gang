# ae studio — лендинг v2 (3D-змея)

Вторая версия лендинга. Контент, тексты, палитра и блоки — как в v1 (корень репозитория), но талисман теперь
настоящая 3D-змея на WebGL (three.js r149, UMD с cdnjs), построенная по раскадровке клиента `storyboard/`.

## Запуск

```bash
python3 -m http.server 8000      # из корня репозитория
# лендинг:      http://localhost:8000/v2/
# лаборатория:  http://localhost:8000/v2/lab/   (20 сцен раскадровки, ползунок времени)
```

## Структура

```
v2/index.html                 — страница (тексты v1; подключены three.js, snake3d.js, snake3d-page.js)
v2/assets/css/style.css       — стили v1 (копия)
v2/assets/css/blocks.css      — стили блоков v1 (копия)
v2/assets/css/v2.css          — правки v2: слой змеи, статичная картинка, размер логотипа
v2/assets/js/snake3d.js       — ядро: скелет, мех, голова, 20 сцен раскадровки
v2/assets/js/snake3d-page.js  — змея на странице (API SohoSnake.mount как в v1)
v2/assets/js/main.js, blocks.js — интерактивы v1 (без изменений)
v2/assets/img/snake-ae-3d.webp — статичный рендер «ae» (нет WebGL / «уменьшить движение»)
v2/lab/                       — лаборатория сцен для сверки с раскадровкой
v2/tools/                     — проверки и сборка (Playwright, Python + Pillow)
```

## Модель (по раскадровке, стр. 03–06)

- Длина от носа до кончика хвоста — 16 максимальных диаметров (D = 1 единица мира). Хвост сужается после 2/3 длины.
- 12 кремовых колец с тёмными краями, привязаны к длине дуги (не «плывут»); первое кольцо сразу за головой.
- Голова — отдельная группа: низкая округлая, широкая мягкая морда, маленькие глянцевые глаза-бусины по бокам.
  Верхняя часть и нижняя челюсть с мехом, нёбо, раздвоенный язык.
- Мех — shell-текстурирование: тело рисуется 16 слоями (на телефоне 11, при просадке кадра меньше) с процедурными
  ворсинками, rim/sheen-освещением, затемнением у корней и у земли, светлым брюхом. Текстуры не нужны: ворс считается
  в шейдере, поэтому одинаково чёткий при любом масштабе (Blender не понадобился).

## Скелет и движение

- 64 позвонка от шейного сустава до кончика хвоста, шаг постоянный. Цели сцены → критически демпфированные пружины →
  проекция длины (растяжения нет) → отталкивание витков → земля.
- Поверх — быстрые FK-надстройки, тоже без растяжения: поворот головы и шеи (сначала голова, потом шея),
  подъём передней части (голова сама выравнивается), бросок, хвост.
- Рамки вдоль тела — минимально вращающиеся, притянутые к «брюхом вниз», плюс поле крена (переворот, наклон головы).
- Переходы между состояниями — смешивание 0.3–0.6 с, все управляющие величины — через пружины.

## Сцены страницы

| Блок | Сцена раскадровки |
|---|---|
| Первый экран | змея за ~2.8 с выписывает «ae», покой и дыхание (01), голова следит за курсором по трём осям (02–04), язык (06), иногда зевает (07), ленивый хвост (05) |
| Клик рядом с головой | бросок и возврат (19) |
| Прокрутка из героя | поворот (12): голова уходит из логотипа и ведёт тело по дуге |
| Бегущая строка | переползание через ленту (13) — поднимается только участок над ней |
| Правое поле | боковая волна (08): волны неподвижны на странице, змея скользит сквозь них |
| «Состав: 100% забота» | переползание через бирку «Рядом 24/7» (13), только на десктопе |
| Калькулятор | обвивание кольца «Цель месяца» (14–15); при росте суммы — сжатие |

Прокрутка вверх возвращает змею по тому же пути обратно в «ae». Если включено «уменьшить движение» или нет WebGL,
в первом экране стоит статичный рендер.
