# ae studio — сайт вебкам-студии

Лендинг для набора моделей 18+. Без фреймворков и сборки: один `index.html`, два CSS-файла и три JS-файла.
Сайт работает с любого статического хостинга (GitHub Pages, Netlify, Cloudflare Pages, обычный сервер).

Структура и подача текстов — по образцу diva.studio (план по блокам: `docs/structure-diva.md`),
стилистика — своя: плюшевая змея, пудровый розовый, полосы «чёрный — крем — чёрный», алерты стрима и полароиды.

## Концепция

**«Мягкий старт. Большой доход.»**

- **Плюшевая розовая змея** — талисман студии. Её тело с кремовыми и чёрными полосами складывается в логотип «ae».
  Мех — это мягкость, уют и забота о модели, змея — притяжение и характер.
- **Первый экран:** змея заползает и выписывает телом «ae», под ней проявляется «studio», как в логотипе.
  Змея смотрит на курсор и показывает язык. По клику она ползёт за курсором, а потом возвращается и снова пишет логотип.
- **След змеи** заменяет пунктирные «маршруты самолётика» DIVA: змея проползает по странице до калькулятора,
  змея-линия ведёт по полароидам «Пути модели».
- **Полоса змеи** (чёрный — крем — чёрный) — фирменный приём: стыки секций, подчёркивания, прогресс-бары, бегущая строка.
- **Видоискатель камеры** — второй мотив: рамки кадра, REC, таймкод.

Шрифты: Onest (заголовки и текст), JetBrains Mono (подписи).

## Структура

```
index.html            — разметка и все тексты
assets/css/style.css  — стили, цвета, шрифты, первый экран, адаптив
assets/css/blocks.css — чат FAQ, пропуск-анкета и блоки по структуре DIVA
assets/js/snake.js    — движок плюшевой змеи (canvas)
assets/js/main.js     — интерактивы страницы (калькулятор, чек-лист, алерты, форма, отзывы…)
assets/js/blocks.js   — чат FAQ, пропуск-анкета
assets/img/            — мех, рендер змеи, атласы меха из Blender (snake/)
dev/snake.html        — отдельная страница для настройки змеи
```

Важно для змеи: секции между первым экраном и калькулятором (`#fit`, `#conditions`, площадки, `#format`)
не должны создавать stacking context (`isolation`, `transform`, `filter`, `opacity`, `z-index` на самой секции),
контент внутри — на `z-index` ≥ 4. Подробнее — в `style.css` (раздел SNAKE LAYER) и в комментариях `snake.js`.
Положение логотипа на десктопе задано одной формулой в двух местах: `logoBox()` в `snake.js` и `.hero` в `style.css` (`min-width: 960px`).

### Скрытые шаблоны — включить, когда будут реальные данные

- **«Сколько существует студия?»** — в FAQ стоит `<details class="acc" hidden>` с текстом-заглушкой.
  Впишите год основания и пару слов о команде и уберите `hidden`. Чат подхватит вопрос сам.
- **Основатели** — блок `<div class="founders" data-founders hidden>` в `#about`. Замените `[Имя]`, текст и
  иллюстрацию на фото (`.founder__photo` → `<img>`), добавьте карточки и уберите `hidden`.
- **Отзывы** — см. следующий раздел.

Отзывы, людей и цифры на сайте не выдумываем.

## Отзывы: как добавить скриншоты

Блок `#reviews` скрыт, пока в нём нет данных. Чтобы включить:

1. Получите **согласие** моделей. Скройте на скриншотах имена, аватарки и всё, что может их выдать.
2. Положите файлы в `assets/img/reviews/` (лучше `.webp`, ширина ~600 px).
3. Впишите их в JSON внутри блока (`<script type="application/json" data-reviews-data>`):

```json
[
  { "src": "assets/img/reviews/01.webp", "alt": "Переписка: модель благодарит куратора за первую неделю", "width": 600, "height": 1200 },
  { "src": "assets/img/reviews/02.webp", "alt": "…", "caption": "первая выплата" }
]
```

Блок появится сам: карусель со свайпом и кнопками ← →. Поле `alt` обязательно опишите словами — его читают скринридеры.

## Как подключить анкету

Сейчас анкета отправляется «вхолостую»: показывает экран успеха, но данные никуда не уходят.
Укажите адрес приёма в атрибуте `data-endpoint` у формы:

```html
<form class="form" data-form data-endpoint="https://ваш-адрес-приёма" ...>
```

Форма отправит `POST` с JSON: `name`, `contact` (телефон или ник), `contactType` (`phone` / `telegram`),
`place` (`studio` / `home`), `adult: true`, `consent: true`.
Подойдут Formspree, Make/Zapier-вебхук или свой обработчик, который пересылает заявку в Telegram-бот менеджера.
