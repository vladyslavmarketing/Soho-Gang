# ae studio — сайт вебкам-студии

Лендинг для набора моделей 18+. Без фреймворков и сборки: один `index.html`, один CSS-файл и два JS-файла.
Сайт работает с любого статического хостинга (GitHub Pages, Netlify, Cloudflare Pages, обычный сервер).

## Концепция

**«Мягкий старт. Большой доход.»**

- **Плюшевая розовая змея** — талисман студии. Её тело с кремовыми и чёрными полосами складывается в логотип «ae».
  Мех — это мягкость, уют и забота о модели, змея — притяжение и характер.
- **Первый экран:** змея заползает и выписывает телом «ae», под ней проявляется «studio», как в логотипе.
  Змея смотрит на курсор и показывает язык. По клику она ползёт за курсором, а потом возвращается и снова пишет логотип.
- **Полоса змеи** (чёрный — крем — чёрный) — фирменный приём: разделители, подчёркивания, прогресс-бары, бегущая строка.
- **Видоискатель камеры** — второй мотив: рамки кадра, REC, таймкод, 4K и 5600K.

Стиль: пудрово-розовый фон, как в фотостудии, плюшевый мех, кремовый и чёрный из полос змеи.
Шрифты: Onest (заголовки и текст), JetBrains Mono (подписи видоискателя).

## Что на странице

| Раздел | Что интерактивного |
|---|---|
| Первый экран | Плюшевая змея на canvas выписывает логотип «ae», смотрит на курсор, по клику ползёт за ним. Факты — плюшевые стикеры |
| Путешествие змеи | При прокрутке змея выползает из логотипа, ползёт по краю страницы под блоками и обвивает кольцо калькулятора. При прокрутке вверх снова складывается в «ae» |
| «Состав: 100% забота» | Преимущества в виде пришитых бирок мягкой игрушки, качаются от курсора |
| Калькулятор дохода | Виджет «Цель месяца» как на стриме: ползунки, уровень опыта, всплывающие «чаевые» |
| Комнаты | Мультикам-пульт: большой монитор ON AIR и четыре камеры, переключение с монтажной склейкой, свет вкл/выкл |
| Как начать | Пять полароидов на полосатом скотче, змея проползает между ними при прокрутке |
| Анонимность | Переключатели «гео-блок / псевдоним / без лица» меняют превью эфира, глобус показывает скрытый регион |
| Вопросы | Чат частых вопросов: выбираешь вопрос, ответ «печатается» |
| Анкета | Пропуск BACKSTAGE на шнурке: 3 шага, проверка полей, черновик сохраняется, штамп «ПРИНЯТО» |
| Подвал | Мех и большой плюшевый логотип, по меху ползает вторая змея |

Анимации отключаются, если в системе включено «уменьшить движение», а кнопка «Остановить анимацию» ставит их на паузу.

## Запуск локально

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

## Публикация на GitHub Pages

Settings → Pages → Source: «Deploy from a branch» → ветка `main`, папка `/ (root)`.

## Что заменить перед запуском

Все цифры и контакты на сайте — примеры. Проверьте и замените их на реальные:

- **Telegram** `@ae_studio_cam` — в подвале (`index.html`, ищите `ae_studio_cam`).
- **Ставки калькулятора** — атрибуты `value` у радиокнопок `name="level"` (долларов в час: 12 / 22 / 38).
- **Факты в первом экране** — выплаты по понедельникам, 0 грн за обучение, менеджер 24/7.
- **Комнаты** — названия, площадь, свет. Сейчас вместо фото стоят CSS-иллюстрации в мультикаме (`.mc-room`);
  реальные фото и короткие видео комнат сильно повысят доверие (см. отчёт по конкурентам).
- **FAQ** — особенно ответ про процент студии.

## Как подключить анкету

Сейчас анкета отправляется «вхолостую»: показывает экран успеха, но данные никуда не уходят.
Укажите адрес приёма в атрибуте `data-endpoint` у формы:

```html
<form class="form" data-form data-endpoint="https://ваш-адрес-приёма" ...>
```

Форма отправит `POST` с JSON (`name, age, city, channel, contact, shift[], experience, about`).
Подойдут Formspree, Make/Zapier-вебхук или свой обработчик, который пересылает заявку в Telegram-бот менеджера.
